# 终末地小助手

Windows 上的《明日方舟：终末地》配队、技能轴编辑与悬浮提示工具。

**[下载最新版](https://github.com/yjlovegy/endfield-assistant/releases/latest)**

在版本页面下载 `EndfieldAssistant-版本号-win.zip`，完整解压后运行。`Source code` 是本发布仓库的文档压缩包，不是软件。

## 功能

- 自选干员组队，编辑多条可命名、折叠、复制的技能轴。
- 透明悬浮窗显示技能图标和按键，可分批显示，也可以每条轴独立显示。
- 按下对应键后推进，支持键盘、鼠标、组合键以及长按判断。
- 在技能前后添加轴内提示，调整字体、字号和颜色。
- 统一设置长按时间，也可单独修改每一步。
- 深浅主题切换、最小化到托盘、软件内检查更新。

## 使用

1. 完整解压 ZIP 到可读写文件夹。
2. 双击 `启动终末地小助手（管理员）.cmd`，在 Windows 提示中确认。
3. 选择队员和技能，设置对应按键，编辑并保存技能轴。
4. 打开悬浮窗，点击“启动”，切回游戏。

工具只根据你的键鼠操作推进提示，不会代你向游戏发送按键。

## 在线更新与数据

从 **1.0.1** 开始，软件启动时会后台检查更新，也可点击右上角“检查更新”。发现新版后点击更新，确认后下载、校验、保存当前方案并重启。

配队、技能轴、快捷键和设置保存在程序旁的 `data` 文件夹。在线更新保留此文件夹；公开下载包不包含个人方案。

旧 V1.0 首次升级需要手动下载：先保存并退出旧版，将旧版的 `data` 文件夹复制到新版 `EndfieldAssistant` 文件夹中，再运行新版。以后使用软件内更新即可。

换电脑时请复制整个程序文件夹，包括 `data`。自选字体需在新电脑安装，否则会使用系统替代字体。

## 系统要求

- Windows 10 / Windows 11。
- .NET Framework 4.8 或 4.8.1；不需要开发工具。
- 在线检查和下载更新需要能够访问 GitHub。没有网络时可以继续使用本地功能。
